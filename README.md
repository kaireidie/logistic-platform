## Environment Variables

| Variable | Description |
|----------|-------------|
| `DB_URL` | PostgreSQL JDBC URL |
| `DB_USERNAME` | Database username |
| `DB_PASSWORD` | Database password |

### Example

```text
DB_URL=jdbc:postgresql://localhost:5432/logisticsystem
DB_USERNAME=admin
DB_PASSWORD=admin
```
